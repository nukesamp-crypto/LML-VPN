# LML VPN 1.0.1 — راهنمای ویندوز

این پوشه شامل رابط اصلی HTML/CSS/JavaScript، برنامهٔ Electron، آزمون‌ها، درخت اصلاح‌شدهٔ Radiance و اسکریپت‌های Windows x64 است. راهنمای دریافت، امکانات و محدودیت‌ها در [README مخزن](../README.md) و دستورهای کامل ساخت در [راهنمای ساخت ویندوز](../docs/BUILD-WINDOWS.md) آمده‌اند.

نسخهٔ ۱.۰.۱ فهرست کانفیگ را از کانال‌های عمومی و فید DNS می‌گیرد. در صفحهٔ کانفیگ این نسخه، ورود دستی، اشتراک، QR و بازیابی وجود ندارند. TheFeed و موتورهای شبکه سرویس‌هایی مستقل‌اند و دسترس‌پذیری آن‌ها به شبکه وابسته است.

نصاب x64 به دسترسی مدیر نیاز دارد، امضای تجاری ندارد و در این نوبت روی دستگاه واقعی ویندوز تست نشده است. پراکسی ویندوز همهٔ برنامه‌ها را پوشش نمی‌دهد و Kill Switch ندارد. پیش از نصب و هنگام استفاده از سرورهای عمومی، هشدارهای README را بخوانید.
